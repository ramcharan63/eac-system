Stage 1: Schema Validation
Every ActivityRecord entering the pipeline is validated against the 39-field schema definition. Required fields trigger rejection on absence; optional fields are flagged for the readiness score. Type checks enforce: numeric fields (Hours_Logged, CapEx_Eligible_Pct, ActualSpend_USD) accept only parseable numbers; enum fields (VZZ_CostClass, Activity_Type, LaborSurvey_Category) are validated against allowed values; string fields are trimmed and null-checked. Records failing validation are written to the dead-letter queue with field-level error detail — they do not proceed through the pipeline.
